# CLAUDE.md

Тестовый (пет) проект на Angular, который мы делаем вместе с Claude: каталог стран на данных REST Countries v5.

**Статус: функционально закончен.** Решения пользователя: продакшен-деплой не нужен (прокси с ключом работает только в `ng serve`), роутинг не нужен (для проекта такого размера). Дальнейшие правки — по запросам пользователя.

## Запуск и команды

- `npm run dev` (или `npm start`) — `ng serve`, http://localhost:4200
- `npm test` (`ng test`, для разового запуска `ng test --watch=false`) — Vitest + jsdom, 21 тест
- `npm run build` — сборка (проверка, что всё компилируется)
- После изменения `proxy.conf.mjs` dev-сервер нужно перезапускать. Если сервер на 4200 отдаёт старый бандл — перезапустить; для проверок я поднимал отдельный `ng serve --port 4300` и потом останавливал.
- Среда — Windows. Предупреждения git «LF will be replaced by CRLF» нормальны.

## Правила работы

- **Язык:** общение по-русски. Текст интерфейса — на английском (как и данные API).
- **Секреты:** ключ API лежит в `.env` (`REST_COUNTRIES_API_KEY`), файл в `.gitignore`; шаблон — `.env.example`. Значение ключа не писать в CLAUDE.md, код, коммиты и ответы.
- **Коммиты и push** — только по просьбе пользователя. Коммитить лучше после каждого законченного шага, а не пачкой.
- **Проверка:** UI-правки проверять в браузере (десктоп и 375px), логику store — тестами (`ng test`). Значения `getComputedStyle` во время CSS-переходов в неактивном окне браузера не продвигаются — анимации смотреть по скриншоту.
- **Ведение файла:** при значимом изменении обновлять разделы ниже (архитектура, решения, ограничения), а в «Журнал» добавлять одну строку. Подробная история — в git.
- **Режим «Senior Developer — Mentor» ВРЕМЕННО ОТКЛЮЧЁН** (пользователь спешит). Включить по просьбе. Суть режима: небольшие этапы; перед кодом объяснять что, почему, какие файлы и как это вписывается в архитектуру; после кода — как работает и почему не проще; предлагать пользователю написать часть кода самому; не соглашаться автоматически, называть риски и альтернативы; после этапа 1–2 вопроса на проверку понимания; не создавать лишних абстракций. Главный принцип: скорость разработки не опережает понимание.

## Архитектура

Данные текут в одну сторону: **API → Store → компоненты**; компоненты сообщают о действиях через `output()`, а решения принимает родитель или store.

```
App
├── Header (sticky, бургер-меню на ≤768px) ── HeaderButton × 7 (6 регионов + «All countries»)
└── Content
    ├── placeholder «Select a region»       (регион не выбран)
    ├── CountryBoard                        (регион выбран, страна не открыта)
    │   └── RequestStatus (Loading / ошибка + Try again / содержимое)
    │       ├── CountryCard × до 30 (клик → store.openCountry)
    │       └── CountryPagination ── Button × (‹, 1…N, ›)
    └── CountryOverview                     (страна открыта)
        ├── Button «← Back» → store.closeCountry
        └── RequestStatus → Description / General information / Memberships
```

- **`CountryApi`** (`services/country-api.ts`) — единственное место с HTTP. `getCountries(region | null)` — весь регион или все страны страницами по 100 через `expand` (`meta.more`); `getByName(name)` — одна страна.
- **`CountryStore`** (`services/country-store.ts`) — всё состояние на сигналах: `selectedContinent`, `countries` (срез текущей страницы, 30 на страницу, пагинация на клиенте), `page`, `totalPages`, `count`, `loading`, `error`, `openedCountry` (карточка, на которую нажали), `details` / `detailsLoading` / `detailsError` (полные данные), кэш деталей `detailsCache` по `names.common`. Методы: `loadByContinent`, `retry`, `setPage`, `openCountry`, `closeCountry`, `retryDetails`. Новый запрос отменяет предыдущий (`unsubscribe`), `closeCountry` отменяет незавершённый запрос деталей. RxJS используется только для HTTP.
- **Модели** (`models/`): `Country` (все 35 полей API), `Continent` (`{ region: Region | null; label }`, `CONTINENTS`, `ALL_COUNTRIES`), `Region` (enum, значения совпадают с параметром API).
- **Общие компоненты:** `app-button` (`label`, `active`, `disabled`, `pressed`), `app-request-status` (`loading`, `error`, `errorMessage`, `retry`; `:host { display: contents }`, чтобы не ломать flex-раскладку родителя), `app-header-button`.
- Сервисы объявлены через `@Service()` (новый декоратор Angular); суффикс `.service` в именах файлов не используем.

## REST Countries API v5 — неочевидные факты

- URL: `https://api.restcountries.com/countries/v5`, ключ в заголовке `Authorization: Bearer`. Из браузера API с localhost отвечает 403 (пускает только origin'ы из настроек ключа), поэтому запросы идут через dev-прокси `proxy.conf.mjs` (`angular.json` → `serve.options.proxyConfig`): `/api/*` → `api.restcountries.com`, прокси сам читает ключ из `.env`, добавляет заголовок и убирает `Origin`.
- Ответ: `data.objects` + `data.meta` (`total`, `count`, `limit`, `offset`, `more`). Лимит free-тарифа — 100 записей на запрос; всего 254 страны.
- **Работают фильтры:** `region`, `subregion`, `continents`, `memberships.<org>=true`, `names.common` (точное совпадение), `q` (широкий текстовый поиск), `response_fields`. **Не работают** (молча игнорируются, API отдаёт всё): `sort`/`order`, числовые условия (`population.gt`), фильтры по массивам (`languages.name`, `currencies.code`), неизвестные параметры, поиск по `uuid`.
- Отдельного эндпоинта для одной страны нет. Страна ищется по `names.common`, потому что у Abkhazia, Northern Cyprus, Somaliland, South Ossetia нет кодов `alpha_2`/`alpha_3` (и флага).
- Картинки — только флаги (`flag.url_svg`, `flag.url_png`, эмодзи); фото нет. `leaders` на free-тарифе — только сообщение о платном доступе. `null` бывает лишь в `flag.colors.swatches.*`, пустые строки — в `parent.*`, `flag.url_*` у территорий.
- API периодически отвечает 500 или долго висит (≈25–30 с) — при ошибке показывается «Try again». Автоповтор решено не делать.
- Экономика в данных — только коэффициент Джини по годам (у 83 стран его нет).

## Стили и соглашения

- SCSS, стили компонентов инкапсулированы. Глобально: `styles.scss` (`--content-width: 1440px`, `--content-padding-*`, `.container`), `styles/_fonts.scss` (Arial), `styles/_colors.scss`.
- **Все цвета — только переменные в `_colors.scss`**, новые цвета добавлять туда. Есть токены текста (`--color-text`, `--color-text-strong`, `--color-text-muted`), рамок (`--color-border` #d4d4d4), кнопок (`--color-button-*`, активная страница — зелёный текст), меток (`--color-yes-*`, `--color-no-*`, `--color-invalid-*`), подложек (`--color-content-bg`, `--color-header-bg`).
- Подход **desktop-first**, единственная точка перелома — `@media (max-width: 768px)`. Любое десктопное свойство, мешающее мобильной версии, нужно явно перебивать внутри `@media` (так был баг с `height: 100%` у выпадающего меню).
- Header: `position: sticky; top: 10px`, на 20px шире контента (1480px), полупрозрачный с `backdrop-filter`. Стекло вынесено в `.header::before`, а не на `.header`: иначе `.header` становится «корнем фона» (backdrop root), и вложенное меню не размывает страницу под собой. Общий «стеклянный» вид — SCSS-миксин `glass`.
- Мобильное меню header анимируется через `opacity` + `transform` + `visibility` (не `display`): `visibility: hidden` убирает пункты из Tab и скринридеров; задержка `visibility` в transition даёт анимации закрытия доиграть.
- Сетка карточек: максимум 4 в ряд, минимальная ширина карточки = её ширина при 5 в ряд в контейнере 1440px. Hover-эффект карточки (зум 1.03 и тень) — только в `@media (hover: hover)`.
- Пагинация держит позицию на экране: `goTo(page)` запоминает `top` блока и после рендера докручивает `window.scrollBy`.
- Для динамических значений привязки `[x]="…"`, для постоянных — обычные атрибуты; для `aria-*` с динамическим значением — `[attr.aria-…]`.
- **Тесты** (`*.spec.ts` рядом с кодом): `country-store.spec.ts` (загрузка, отмена устаревшего запроса, пагинация, открытие/закрытие страны, кэш, ошибки), `header.spec.ts` (меню), `app.spec.ts` (интеграция: регион → карточки → страна → Back). API подменяется через `{ provide: CountryApi, useValue: … }`. После правок store запускать `ng test`.

## Известные ограничения (осознанно не делаем)

- Нет продакшен-деплоя: ключ API в проде был бы виден, нужен был бы свой бэкенд/прокси.
- Нет роутинга: открытая страна, регион и страница живут только в памяти (нет URL, не работает «Назад» браузера, обновление страницы сбрасывает состояние).
- `CountryStore` объединяет список и детали страны; при росте проекта его стоит разделить.
- Страна идентифицируется по `names.common` (обходной путь из-за API); списки регионов не кэшируются (детали — кэшируются); «All countries» тянет 254 полных записи.
- После «Back» страница пагинации сохраняется, а позиция прокрутки — нет.
- У `<article>` карточки стоит `role="button"` и внутри лежат ссылки — компромисс по доступности (лучше кнопка в заголовке с растянутой областью клика).
