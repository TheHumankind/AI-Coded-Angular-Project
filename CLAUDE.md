# CLAUDE.md

Это тестовый проект на Angular, который мы делаем вместе с Claude.

## Запуск

- Dev-версия: `npm run dev` (или `npm start`) — `ng serve`, http://localhost:4200

## Правила ведения файла

После каждого значимого шага добавляй сюда запись в журнал ниже (что сделано и текущее состояние проекта), чтобы сохранять контекст между сессиями.

## Журнал шагов

1. Создан Angular-проект в корне папки (CSS, без роутинга и SSR, без git). Шаблон `src/app/app.html` пустой. Добавлены npm-скрипты `dev` и `start` (оба `ng serve`). Dev-сервер проверен, работает на порту 4200.

4. Создан компонент `header` (`src/app/components/header`, селектор `app-header`), подключён в `App`. Header на всю ширину, фон `rgba(255, 0, 0, 0.5)`, высота `min-height: 64px` (без неё пустой header невидим), внутри пустой `.container`, без кнопок и наполнения. В `styles.scss` добавлены `--content-width: 1440px`, класс `.container` (max-width 1440px по центру) для всего проекта и `body { margin: 0 }`.
5. Создан компонент `content` (`src/app/components/content`, селектор `app-content`), подключён в `App` под `app-header`. Блок `<main class="content">` с `max-width: var(--content-width)` (1440px), отцентрирован, `min-height: 64px`, фон `rgba(0, 255, 0, 0.5)`, внутри пустой `.container`, без наполнения.
6. Блок `content` растянут на всю оставшуюся высоту страницы: `App` — flex-колонка с `min-height: 100vh`, `app-content` и `.content` с `flex: 1`; у `content` убран `min-height: 64px` (он больше не нужен). Header остаётся 64px, у `app-header` добавлен `display: block`.
7. Тема проекта — страны, данные из REST Countries. Ключ API лежит в `.env` (переменная `REST_COUNTRIES_API_KEY`), файл добавлен в `.gitignore`; шаблон без секрета — `.env.example`. Значение ключа не записывать в CLAUDE.md, код и коммиты. Ключ пока нигде не подключён в коде.

Сервисы объявлены через `@Service()` (новый декоратор Angular, суффикс `.service` в именах не используем).

Подключён через `@use 'styles/colors'` в `styles.scss`, применён к `body` и явно к `.header`; кнопки наследуют цвет. Новые цвета добавлять в этот файл.

Инициализирован git (ветка `main`), сделан первый коммит; `.env` проверен — в индекс не попадает. Удалённый репозиторий GitHub `AI-Coded-Angular-Project` пока не создан (`gh` не установлен). 15. Первый реальный запрос к REST Countries. API — v5 (`https://api.restcountries.com/countries/v5`), ключ передаётся заголовком `Authorization: Bearer`; ответ в обёртке `data.objects` / `data.meta`, free-лимит до 100 записей на запрос. Из браузера API пускает только origin'ы из настроек ключа (с localhost — 403), поэтому запросы идут через dev-прокси `proxy.conf.mjs` (подключён в `angular.json` → `serve.options.proxyConfig`): путь `/api/*` → `api.restcountries.com`, прокси читает ключ из `.env`, добавляет заголовок и убирает `Origin`. Ключ в браузерный код не попадает. Работает только в `ng serve` (для prod-сборки понадобится свой бэкенд/прокси). `CountryApi.getByRegion(region)` (поля `names.common`, `codes.alpha_2`, `region`), модель `Country` и `CountriesResponse` обновлены под v5. `CountryStore.loadByContinent` теперь делает тестовый запрос: любая кнопка грузит `region=Europe` (54 страны) и логирует в консоль `request sent` / `response received`. Заглушка «Выберите страну» (uppercase, по центру) перенесена в `content` и показывается, пока ничего не выбрано; `country-board` показывается после клика. Проверено в браузере. После изменения `proxy.conf.mjs` нужно перезапускать `npm run dev`.
16. У каждой кнопки свой запрос. Добавлен enum `Region` (`src/app/models/region.ts`): Africa, Americas, Asia, Europe, Oceania, Antarctic — значения совпадают с параметром `region` API (проверено: 60/56/52/54/27/5 стран, все в пределах лимита 100). `Continent` теперь `{ region: Region; label: string }`, список кнопок — константа `CONTINENTS` в `continent.ts` (вместо генерации «Continent N»); подписи кнопок — названия регионов. `CountryApi.getByRegion` принимает `Region`. `CountryStore.loadByContinent` запрашивает `continent.region` и отменяет предыдущий незавершённый запрос (`Subscription.unsubscribe`), чтобы при быстрых кликах старый ответ не перезаписал новый. Проверено в браузере для всех 6 кнопок.
17. Полная модель страны: `src/app/models/country.ts` описывает все 35 полей ответа API v5 (названия с переводами, коды, флаг с цветами, столицы, языки, валюты, членства, даты, ссылки и т.д.), разбитые на вложенные интерфейсы (`CountryNames`, `CountryFlag`, `CountryCapital`…). Структура выведена по всем 254 записям API: необязательных полей нет, `null` бывает только в `flag.colors.swatches.*`; при этом часть строк может быть пустой (например, `flag.url_svg` у Абхазии, `parent.*` у независимых стран). Поля с динамическими ключами (коды языков, годы) — `Record<string, …>`. `leaders` на бесплатном тарифе содержит только сообщение о платном доступе. `CountryApi.getByRegion` больше не ограничивает поля (`response_fields` убран) и грузит максимум 30 стран (`PAGE_SIZE = 30`); в регионах больше 30 стран (Africa, Americas, Asia, Europe) приходит первая страница, `meta.more = true`. Одна загрузка ≈ 170 КБ, ≈ 1 с. Проверено в браузере.
18. Карточки стран. Компонент `country-card` (`src/app/components/country-card`, input `country: Country`): высота 400px, сверху `<h2>` с `names.common` (uppercase, 700), ниже `descriptions.short`, затем площадь (`area.kilometers`, km²) и население (`population`) через `DecimalPipe`. Внизу (`margin-top: auto`) 4 квадратные кнопки-ссылки 36×36: Google Maps, Official website, OpenStreetMap, Wikipedia — это `<a target="_blank" rel="noopener noreferrer">` с самодельными SVG-иконками (метка, глобус, карта, буква W), не оригинальные логотипы. Если ссылки у страны нет (official пуст у 57 стран, карты — у 4), кнопка остаётся на месте, но неактивна: без `href`, `aria-disabled`, прозрачность 0.35. `country-board` выводит сетку 5 колонок (gap 16px) из `store.countries()`, на время загрузки — «Loading…», при ошибке — «Failed to load countries». Подписи на карточках на английском (как и данные API). В `_colors.scss` добавлены `--color-text-muted`, `--color-border`, `--color-card-bg`, `--color-hover`. Проверено в браузере (Europe: 30 карточек, 5 в ряд, ссылки рабочие).
19. У карточек убрана фиксированная высота 400px: `.country-card` теперь `height: 100%`, а CSS Grid по умолчанию (`align-items: stretch`) растягивает все ячейки ряда по самой высокой карточке. Кнопки-ссылки по-прежнему прижаты к низу. Проверено на Africa: в рядах с двухстрочным названием карточки по 248px, в остальных по 226px, внутри ряда высота одинаковая. REST Countries временами отвечает 500 или долго висит (видели и при прямых запросах) — это сторона API, при ошибке выводится «Failed to load countries», повторный клик помогает.
20. Сетка карточек: максимум 4 в ряд на всю ширину `country-board`; минимальная ширина карточки — её ширина при 5 в ряд в контейнере 1440px (`--card-min-width: calc((var(--content-width) - 4 * var(--grid-gap)) / 5)` ≈ 275px, `--grid-gap: 16px`). Реализовано через `repeat(auto-fill, minmax(max(min(--card-min-width, 100%), (100% - 3·gap) / 4), 1fr))`: на узких экранах колонок меньше (1000px → 3, 700px → 2), но карточка не уже минимума. В карточку добавлены строки Capital (все столицы через запятую), Languages (все языки), Calling code (`+` + код), Code (`alpha_2 / alpha_3`) — над площадью и населением. Строки собираются в `computed` `details` и с пустым значением не выводятся (например, у Antarctica нет Capital и Languages). Значения в строках выровнены вправо и переносятся. Проверено в браузере (Africa, Antarctic). REST Countries продолжает периодически отдавать 500 примерно через 25–30 с (воспроизводится и при прямых запросах без прокси).

Failed to load countries.» и кнопку «Try again», которая вызывает новый метод `CountryStore.retry()` (повторяет запрос для текущего `selectedContinent`). Автоповтор решено не делать. Заглушка в `content` теперь на английском: «Select a region». У блока `content` отступы 40px сверху/снизу и 20px слева/справа (`box-sizing: border-box`, общая ширина остаётся 1440px); значения — переменные `--content-padding-block` и `--content-padding-inline` в `styles.scss`. Отступ `padding-block: 24px` у `country-board` убран (его заменил отступ content). `--card-min-width` теперь считается от внутренней ширины content: (1440 − 2·20 − 4·16) / 5 ≈ 267px; карточка при 4 в ряд — 338px. Проверено в браузере, включая ошибку (сымитирована подменой URL) и повтор через «Try again».
